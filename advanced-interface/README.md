# Serene / Blue — Advanced Interface

Weekly interactive components for Advanced Interface (ArtCenter), combined into one design system for the final.

- `index.html`: landing page that lists every week
- `wk01-loaders/`: Week 1, progress indicators (Capsule, Petal, Pool)

Each week gets its own folder with an `index.html`. Design tokens (colors, motion timings) match the Figma variables in the Serene / Blue file.
